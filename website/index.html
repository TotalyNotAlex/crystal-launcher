FAQ

Frequently asked questions

Got a question? We've got answers.

Is Crystal Launcher free?
Yes! Crystal Launcher is completely free and open source. Download and use it without any cost — forever.
Do I need a Minecraft account?
Yes — you need a valid Microsoft account with Minecraft Java Edition purchased. Crystal Launcher uses official Microsoft authentication, so your account is always secure.
Which Windows version is supported?
Crystal Launcher supports Windows 10 and Windows 11 (64-bit). No macOS or Linux builds are available at this time.
Can I use mods with Crystal Launcher?
Absolutely! Crystal Launcher has a built-in mod browser powered by Modrinth and CurseForge. You can search and install mods, resource packs, shaders and modpacks directly from the launcher — no manual downloads needed.
Does Crystal Launcher update automatically?
Yes! Crystal Launcher checks for updates on every startup and notifies you when a new version is available. Updates download and install with a single click.
How do I get help if something doesn't work?
Join the Discord server — we're happy to help there! You can also open an issue on GitHub.
