# Crystal Launcher Overlay Mod

A Feather-style client overlay mod for Minecraft 1.21.11 built on Fabric.

## Keybinds & Access
- **Right Shift**: Open the Overlay Settings Screen
- **Escape Menu**: Click the "Overlay Settings" button under Options

## Features
- FPS, Ping, CPS, and Coordinates HUD overlay
- Full positioning, scaling (0.5x - 2.0x), custom colors for each element
- Live preview in the settings screen
- Fully localized keybinds and categories

## Build Instructions
1. Ensure Java 21 is installed.
2. Run the following command in this directory:
   ```bash
   ./gradlew build -x test
   ```
3. Find your built JAR in `build/libs/crystallauncher-overlay-1.0.0.jar`.
